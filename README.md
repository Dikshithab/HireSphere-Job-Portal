# HireSphere – AI-Powered Job Portal

A full-stack job portal built with React, Django REST Framework, PostgreSQL, and AI-powered resume analysis.

## 🌐 Live Demo

**Frontend:** https://hiresphere-frontend-mn01.onrender.com

**Backend API:** https://hiresphere-backend-6ksv.onrender.com

## 🚀 Features

- User authentication with JWT
- Job seeker and employer roles
- Employer company management
- Job posting and management
- Advanced job search and filters
- Save/unsave jobs
- Job applications
- Employer application management
- Application status notifications
- Real-time unread notification badge
- AI-powered resume analysis
- ATS score and skill analysis
- Responsive React UI
